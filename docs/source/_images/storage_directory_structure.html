Directory Structure of Centralized Storage Buckets

<storage_mount>/1Local mount of a storage share (access limited to approved users)
└── projects/
├── <contract_year>_<funding_source>/2One folder per contract / funding source
│ ├── <project_title>/3One folder per project
│ │ ├── code/4Project scripts and JSON control files
│ │ ├── sourcedata/Original DICOM images from the MRI, before conversion
│ │ ├── rawdata/BIDS dataset of NIfTI images and sidecar JSON files
│ │ │ ├── dataset_description.jsonRequired BIDS dataset metadata
│ │ │ ├── participants.tsvOne row per subject (participant_id and demographics)
│ │ │ ├── participants.jsonDescribes the columns of participants.tsv
│ │ │ └── sub-<label>/One folder per subject
│ │ │ └── ses-<label>/One folder per session (scan visit)
│ │ │ └── <data_type>/e.g., anat, func, dwi, fmap, perf
│ │ └── derivatives/Pipeline outputs (e.g., fmriprep/, aslprep/), kept separate from raw data
│ └── <project_title>/Additional projects under the same contract
└── <contract_year>_<funding_source>/Additional contracts
Shaded rows (level 4) are the BIDS directories created inside every project folder.
